# SullyOS L2D 桌面与视频通话改造提示词

## 任务角色

你是 SullyOS 的游戏 UI / UX 设计师与前端工程师。请直接在现有产品中优化 L2D 桌面和视频通话界面；保留原有角色、背景、通话能力和数据结构，不生成带界面的背景图，不用大量互相竞争的卡片掩盖角色。

## 参考图提炼

- 角色必须是第一视觉中心，像二次元养成游戏主界面的“看板娘”，而不是被面板夹住的普通预览图。
- 功能围绕角色分层：顶部只放身份与轻状态；左右放低频快捷入口；底部放最常用主操作；所有控件主动避让脸部和身体重点区域。
- 从参考图吸收轻巧的游戏语汇：圆形或异形快捷按钮、丝带式导航、微型通知点、任务/亲密度状态、闪光与漂浮装饰、按下回弹；不要照搬资源货币、商城和十几个入口。
- 视觉兼顾 SullyOS 现有的梦幻感与现代清晰度：奶油白 / 深夜蓝作为稳定底色，角色主题色作唯一主强调色，小面积使用樱粉、星光金或薄荷色。
- 视频通话更像“角色正在陪伴你”的沉浸舞台：信息与字幕贴边，控制器悬浮在下方，背景设置与高级工具退到抽屉中，避免遮挡角色。
- 桌面支持多个一键切换的布局预设，让趣味性来自不同构图，而不是来自更多控件。

## 视觉论点

把整个屏幕做成一张会呼吸的角色海报：柔软半透明材质、游戏式轮廓按钮与清楚的舞台景深，让 L2D 像住在桌面里。

## 内容计划

1. 角色舞台：全屏背景 + L2D 主体，保持最大可视面积。
2. 顶部状态：角色身份、在线/情绪状态、时间或通话时长，保持单行易扫。
3. 快捷操作：桌面按布局预设分布在侧边或底部；通话只保留麦克风、输入、设置、挂断等核心操作。
4. 情境信息：桌面显示一句轻量角色状态/气泡；通话显示对话字幕和当前收音状态。
5. 构图编辑：单独进入编辑模式，提供拖拽移动、缩放、横纵位置、可视窗口/裁剪以及重置和保存；编辑时显示安全框，退出后完全隐藏。

## 布局预设

- `舞台 Stage`：角色居中偏下，左右各一列小型圆形入口，底部弧形/胶囊主导航；最接近日系养成游戏主界面。
- `陪伴 Focus`：角色更大并偏一侧，另一侧只保留角色状态与三枚常用入口；适合欣赏角色和宽屏。
- `轻巧 Mini`：角色偏下，功能集中为底部短托盘，顶部信息极少；适合小屏和不遮挡模型。

布局切换必须即时、有平滑位移动画，并记住用户选择。每套布局共享同一份角色构图数据，避免切换后人物跳回默认位置。

## 角色构图编辑要求

- 桌面 L2D 必须支持直接拖拽角色定位。
- 提供缩放滑杆和 `放大 / 缩小 / 居中 / 适配 / 重置` 快捷操作。
- 支持 X / Y 偏移与裁剪窗口（至少上、下、左、右四个边界或等价的可视框编辑）。
- 实时预览，保存到角色自己的配置；取消时恢复进入编辑前的数据。
- 限制极端数值，避免把角色完全拖出屏幕；提供可见安全框和当前百分比读数。
- 手机触摸与鼠标均可操作；控件可收起，不长期遮挡角色。

## 交互论点

- 进入桌面时：背景轻微推近、角色柔和上浮、功能按钮分批出现，完整过程快速且克制。
- 切换布局时：按钮沿边缘滑到新锚点，角色舞台不闪烁、不重新加载。
- 角色交互时：点击/触碰出现短促星屑、爱心或波纹反馈；主按钮按下有弹性回弹；通知点轻微呼吸。

## 验收标准

- 第一眼先看到角色，再看到最重要操作；不能出现面板比角色更抢眼的情况。
- 常用功能 1 次点击可达，布局切换与构图编辑不超过 2 次点击。
- 小屏 360×640、常见手机 390×844 和桌面窄窗均不溢出；刘海屏安全区有效。
- 不破坏现有 VRM / Live2D 加载、通话、语音输入、背景选择和动作配置能力。
- 动画尊重 `prefers-reduced-motion`，按钮有可读标签和足够触控面积。
